# CONDACT Colab tutorial

A quick-start Google Colab tutorial for [CONDACT](https://github.com/CUNY-CSI-Loverde-Laboratory/conditional_activity) (CONDitional ACTivity), a kinetic framework for mapping allosteric communication from molecular dynamics simulations.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/CUNY-CSI-Loverde-Laboratory/condact-colab-tutorial/blob/main/CONDACT_Colab_Tutorial.ipynb)

**Documentation and step-by-step tutorials:** https://cuny-csi-loverde-laboratory.github.io/condact-colab-tutorial/

The pages are built from the `docs` folder each time it changes, and every tutorial is re-run during the build so the numbers and figures match the current code.

The notebook runs the full workflow on the small example trajectory that ships with the package: choosing state boundaries, computing the conditional activity matrix, testing significance with FDR, and tracing a communication route.

If you use CONDACT, please cite: Onyema, A. C.; Dikeocha, C.; Patel, R.; Moussa, J.; Loverde, S. M. Mapping Allosteric Communication in the Nucleosome with Conditional Activity. J. Chem. Inf. Model. (2026). https://pubs.acs.org/doi/10.1021/acs.jcim.6c00317
